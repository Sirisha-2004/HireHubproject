# HireHub

## Project Overview

HireHub is a full-stack job portal designed to connect job seekers with job opportunities.

## Features

- User registration and authentication
- Job-related data management
- Job application management
- User and job models
- Backend REST API

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- bcrypt
- CORS
- Multer
